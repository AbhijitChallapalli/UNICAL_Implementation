# Data directory

This repository does not distribute OASIS-3 or ADNI imaging, clinical data, participant identifiers, manifests, synthetic PET volumes, case-level predictions, or other derived participant-level records.

Obtain access independently from the data custodians and comply with their current data-use and publication terms:

- [OASIS access request](https://sites.wustl.edu/oasisbrains/request-access/)
- [ADNI data access](https://adni.loni.usc.edu/data-samples/adni-data/)

After authorization, place local inputs under this directory or point the public example configurations to an external protected location. Everything under `data/` is ignored by Git except this file and `.gitkeep`.
