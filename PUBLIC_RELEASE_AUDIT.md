## Implementation details recorded in the README

### 1. PET/uncertainty feature dimensionality mismatch

The published paper and Figure 2 define a separate 18-dimensional PET/uncertainty summary. The retained `scripts/51_prepare_synthetic_pet_gated_features.py` implementation appends additional descriptors and coarse-grid values and emits 93 features. The probability-anchored training entrypoint loads the generated matrix. This detail is stated in the README; no scientific code was rewritten during repository cleanup.

### 2. Synthetic-PET representation mismatch

The publication describes a voxelwise-gated synthetic PET volume encoded by a PET encoder, with a separate 18-dimensional reliability pathway. The retained probability-anchored entrypoint consumes the PET summary-feature matrix. This implementation detail is stated in the README.

### 3. Locked configuration drift

The public example records the publication settings `alpha=0.8` and 20 prespecified seeds. Historical local development configurations are excluded from the public tree.

### 4. Environment provenance

The paper reports Python 3.10.20 and CUDA 12.8. The historical setup helper creates Python 3.11 and installs a PyTorch CUDA 12.6 wheel. An import-derived dependency inventory was created, but no complete published-run lock file was available.

### 5. External-validation entrypoint

No clearly identified, public-safe ADNI3 frozen external-evaluation entrypoint was found in the audited tree. The README therefore reports the published external results and data-access requirements but does not claim that ADNI3 evaluation can currently be reproduced from a single released command.

### 6. License and third-party scope

The MIT License applies to original repository code and documentation. `THIRD_PARTY_NOTICES.md` distinguishes that license from the CC BY 4.0 publication figure, external CoCoLIT materials, and restricted OASIS-3/ADNI data. No CoCoLIT weights or participant data are included.
