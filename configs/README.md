# Configuration files

The `*.example.yaml` files are public-safe templates derived from the project configurations. They contain no participant identifiers or user-specific absolute paths.

Copy an example to an ignored local `*.yaml` file and update only paths for data and artifacts that you are authorized to use. The examples record the published locked values where verified, including `K=4`, uncertainty-gate `alpha=0.8`, and the 20 prespecified evaluation seeds.

The public examples are not a complete data-access or environment lock. See `PUBLIC_RELEASE_AUDIT.md` before attempting reproduction.
